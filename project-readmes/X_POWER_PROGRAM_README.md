## ⚡ Overview

The **X Power Program** platform is designed to eliminate friction in the Kenyan job market. Built as a high-performance web application, it streamlines candidate discovery, applicant tracking, and verified vacancy listings.

### Core Features
* **🎯 Automated Talent Matching:** Intelligent candidate recommendation engine based on skills, location, and experience tier.
* **📱 Mobile-First Accessibility:** Built with lightweight CSS and zero-bloat architecture to load fast on mobile connections.
* **🔍 Structured Vacancy Directory:** Multi-filter search by county, industry sector, contract type, and compensation.
* **📄 Frictionless Application Routing:** Direct candidate profile submission without complicated multi-step forms.

## 🚀 Quickstart

### Prerequisites
* Node.js 18+
* npm or pnpm

### Setup & Development

```bash
# 1. Clone the repository
git clone https://github.com/Kivice/x-power-program.git
cd x-power-program

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```
