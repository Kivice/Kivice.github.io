### ⚡ About Me

I am a **Mathematics and Computer Science student at Kirinyaga University** and a software developer building clean, responsive web platforms and automation tools. I care about the balance between the mathematical logic behind algorithms and the thoughtful design that makes software fast and dependable.

* 🎓 **Academic Foundation:** **BSc in Mathematics and Computer Science** at **Kirinyaga University**, Kenya (Discrete mathematics, algorithms, computational logic, numerical analysis).
* 💻 **Active Projects:** [X Power Program](https://github.com/Kivice/x-power-program) (Kenya employment platform) & [Project Veronica](https://github.com/Kivice/veronica) (Desktop voice assistant & telemetry).
* 🛠️ **Core Technologies:** TypeScript, Python 3, Next.js, Node.js, Relational SQL, Linux Shell, Docker.
* 📍 **Location:** Kenya · Creating and shipping for everywhere.
